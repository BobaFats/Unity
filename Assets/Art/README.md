# Папка для арта

Сюда складывается всё, что нарисовано для игры. Правило одно: **назвали файл как слот — он подключился сам.**

## Как пользоваться

1. Откройте [ART_LIST.md](ART_LIST.md). Там полный список того, что нужно игре: имя файла, что это, размер, подключено или пока заглушка.
2. Положите картинку с таким именем в подходящую подпапку.
3. Unity подключит её сам, как только увидит файл. В Console появится строка `[Арт] Подключено: ...`, а в списке слот получит отметку ✅.
   Если ничего не произошло, выполните **Tools → Vertical Shooter → Art → Apply Art From Assets-Art**.
4. Не знаете, как назвать файл или куда его положить? Кидайте в `Inbox` как есть и напишите Claude — он разберёт и подключит.

## Подпапки

| Папка | Что сюда класть |
|---|---|
| `Inbox` | Всё подряд под любыми именами: наброски, референсы, архив от художника, модели, анимации. Само не подключается |
| `Game` | Бой: герой, враги, боссы, пули, стена, фон, башни |
| `Icons` | Иконки навыков и стихий, портреты |
| `Towns` | Города: фоны, здания, жители, портреты для заданий |
| `Road` | Дилижанс, препятствия, картинки встреч |
| `Audio` | Музыка и звуки. Пока подключаются вручную |

Подпапки нужны для порядка. Игра ищет файл по имени во всей папке `Assets/Art`, поэтому два файла с одним именем в разных подпапках будут спорить за один слот.

## Как называть файлы

Регистр букв не важен. Расширение — `.png` (или `.jpg` для фонов).

| Имя файла | Куда встанет |
|---|---|
| `Player.png`, `EnemyPig.png`, `IconDamage.png` … | Слот каталога: герой, враг, иконка. Все имена — в [ART_LIST.md](ART_LIST.md) |
| `Town_05.png` | Фон панорамы города № 5 |
| `building_castle.png` | Здание «Замок» во всех городах сразу |
| `Town_05_building_castle.png` | Здание «Замок» только в городе № 5 |
| `npc_trader.png` | Портрет жителя во всех городах |
| `Town_05_npc_trader.png` | Портрет жителя только в городе № 5 |
| `encounter_Bandits.png` | Картинка встречи в дороге |
| `skin_Golden.png`, `skin_Golden_icon.png` | Скин оружия и его иконка в лобби |
| `quest_CarlsonJumpsuit.png` | Портрет того, кто выдаёт задание |
| `Player.prefab`, `Player.fbx` | Модель вместо картинки для слота каталога (важнее спрайта) |

## Требования к картинкам

- PNG с прозрачным фоном. Фонам (`Background`, `Town_NN`) прозрачность не нужна.
- Размеры в списке — ориентир. Картинка вписывается в своё место с сохранением пропорций, поэтому важнее попасть в пропорции, чем в точные пиксели.
- Вид сверху. Герой и оружие нарисованы «лицом вверх», враги — «лицом вниз»: они идут сверху и не поворачиваются.
- Один файл — одна картинка. Кадры анимаций кладите в `Inbox`: они назначаются в инспекторе **Character Animations** (см. README проекта, раздел про анимации).
- Файл тяжелее 100 МБ GitHub не примет.

## Если арт не появился в игре

- **Имя не совпало со слотом.** В Console будет строка `? …: имя не совпало ни с одним слотом`. Сверьте имя со списком.
- **У объекта в сцене своё оформление.** В сцене `Battle` герой, стена и фон уже оформлены вручную. «Свой спрайт» и «Своя модель» в компоненте **Visual Slot** важнее каталога. Чтобы увидеть арт из этой папки, очистите эти поля у объекта.
- **Картинка импортирована не как спрайт.** Выделите файл и в Inspector поставьте **Texture Type → Sprite (2D and UI)**, затем **Apply**. Для новых файлов в этой папке это делается автоматически.
