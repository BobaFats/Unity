# Проект мини игры VibeCode

Вертикальный «мясной» 2D-шутер с элементами tower defense и roguelite-похода.
Герой стоит внизу экрана у стены и отстреливает толпы врагов, идущих сверху.
Между боями — деревни с квестгиверами и заданиями, карта похода в духе *Slay the Spire*,
поездки на дилижансе (раннер) и встречи в дороге в духе *Hand of Fate*.

- **Движок:** Unity **6000.6.4f1** (URP 2D, новая Input System, TextMesh Pro)
- **Платформы:** телефон (портрет) и ПК (вертикальное окно 540×960, полный экран тоже работает)
- **Графика:** пока заглушки — цветные фигуры с подписями. Весь арт меняется без правки кода:
  картинка, положенная в `Assets/Art` под именем слота, подключается сама (см. «Как заменить арт»)

## Быстрый старт

1. Установите Unity **6000.6.4f1** через Unity Hub.
2. Склонируйте репозиторий и откройте **корневую папку** (в ней лежат `Assets`, `Packages`, `ProjectSettings`) через *Hub → Add → Add project from disk*.
3. Откройте сцену `Assets/Scenes/Vertical/Menu.unity` и нажмите ▶.
   Чтобы сразу попасть в бой — `Assets/Scenes/Vertical/Battle.unity`.
4. Если видно только окно Game — *Window → Layouts → Default*.

> Первое открытие идёт несколько минут: Unity заново собирает папку `Library` (её нет в git).

## Как выглядит игра

Экран боя (портрет 9×16, на ПК поле стоит по центру, по бокам — фон):

```
┌──────────────────────────────┐
│ Уровень 3/30  До босса 42/200 II│  ← номер уровня, прогресс, пауза
│ ███████████ Стена 300/300      │  ← прочность стены
│ ▓▓▓▓ Ур. 5  32/50 XP           │  ← опыт
│                                │
│   [СВИН] [КУРА]  [СВИН]        │  ← толпы врагов идут сверху вниз
│        [СВИН]   [КУРА]         │
│                                │
│ ═══════[БАШНЯ]════[БАШНЯ]═════ │  ← стена и башни-помощники
│              ╱                 │
│          (ГЕРОЙ)               │  ← герой, оружие следует за прицелом
│ Патроны 12/15             [R]  │  ← патроны и перезарядка
└──────────────────────────────┘
```

Остальные экраны: **главное меню**, **лобби** (уровень, характеристики, выбор скина оружия),
**деревня** (панорама города), **карта похода**, **дилижанс** (раннер на 3 полосы).

## Игровой цикл

```
Главное меню → «Новая игра» (создаётся карта похода этого забега)
   ↓
Лобби → «Начать миссию» → БОЙ → босс повержен → награда (стихия) → ДЕРЕВНЯ
   ↑                                                                  ↓
   └──────────── уровни города ещё не пройдены ← «Продолжить» ────────┤
                                                                      ↓ пройдены все 3 уровня города
                                          КАРТА ПОХОДА → ДИЛИЖАНС → развилка → ДЕРЕВНЯ нового города
```

- В каждом городе — **3 уровня**, в забеге — **10 городов**, всего **30 уровней**.
- Прогресс (опыт, навыки, башни, стихии, подковы, карта) живёт между сценами и **сохраняется на диск** между экранами.
- **Поражение** — повтор уровня. **Конец похода** — победа на 30-м уровне или «Завершить поход»: итоги и слава в **наследие**.

## Бой

**Сцена:** `Battle`.

### Управление
| | ПК | Телефон |
|---|---|---|
| Прицел | мышь | палец по полю (ствол держит последнее направление) |
| Стрельба | **автоматическая** | автоматическая |
| Перезарядка | автоматически, вручную — `R` | автоматически, вручную — кнопка в HUD |
| Пауза | `Esc` / `P` / кнопка «II» | кнопка «II» |

### Как работает
- Враги появляются **группами по 2–4** над верхним краем экрана и идут к стене. У стены останавливаются и бьют её.
- **Поток врагов удваивается каждую минуту** (x1, x2, x4… до x64), одновременно на поле — не больше **80**.
- Стена: **300 HP**. Разрушена — поражение («В лобби» с сохранением прогресса или «Новая игра»).
- Пули — физические: летят по прямой, **упруго отскакивают** от боковых стен поля (угол падения = углу отражения), до 3 отскоков.
- Когда появляется босс — **новые враги перестают появляться**, а уже вышедшие продолжают бой.
- Победа над боссом → выбор стихии → деревня.

### Здоровье врагов растёт
Множители перемножаются:
- **уровень кампании:** +25% за каждый следующий уровень;
- **время боя:** первая минута «льготная», дальше **×1.4 в минуту** (экспонента);
- **уровень героя:** +8% за уровень.

Текущий множитель виден в HUD («HP x2.1»).

## Прокачка

### Опыт
- До следующего уровня нужно **10 × 1.5^(уровень−1)** опыта (экспонента: 10, 15, 22, … ~384 к 10-му).
- Опыт за врага растёт с его сложностью (во сколько раз он крепче базового).

### Награды за уровень
При новом уровне игра встаёт на паузу и предлагает **5 случайных вариантов**:

| Навык | Эффект |
|---|---|
| Урон +20% | урон пули ×1.2 (минимум +2) |
| Пули +1 | веер пуль, до 7 |
| Шире разброс | угол веера, до 70° |
| Скорострельность | задержка выстрела −10% (до 0.12 с) |
| Быстрая перезарядка | −15% (до 0.4 с) |
| Обойма +5 | до 60 патронов |
| **Пробивание** | пуля проходит сквозь врага (+1 за уровень, до 5) |
| **Взрывные пули** | часть урона всем вокруг цели (5 уровней) |
| Башня-помощник | сама стреляет в ближайшего врага, до 5 башен |
| Сила башен | урон башен +25%, стреляют на 12% чаще |
| Стена +50 HP | и полный ремонт |
| Ремонт стены | +50% прочности (если стена повреждена) |
| Стихии | после первого босса (см. ниже) |

### Стихии пуль
Открываются **после первого босса** (за победу над боссом — выбор стихии). Каждая стихия срабатывает со своим шансом
(растёт с уровнем), несколько стихий на одной пуле **складываются**.

| Стихия | Эффект |
|---|---|
| Огонь | горение — урон в секунду |
| Холод | замедление |
| Ветер | отбрасывает врага назад |
| Земля | критический урон |

Новая стихия = класс-наследник `ElementDefinition` + ассет в `Assets/Resources/ElementCatalog`.

### Скины оружия
Выбираются в лобби стрелками `<` `>`: «Стандарт», «Бластер», «Золотое».
Новый скин: *Create → Shooter → Weapon Skin* → добавить в `Assets/Resources/WeaponSkinCatalog`.

## Враги и боссы

| Враг | Особенности |
|---|---|
| Свинья | 8 HP, медленная, бьёт стену на 5 |
| Курица | 5 HP, быстрая, бьёт на 3 |
| **Босс** | щит и спецприёмы по уровню (ниже) |
| **Йог-Сотот** | мини-босс уровней 4–30 |
| Щупальце | часть механики Йог-Сотота |

### Способности босса
Задаются флажками в ассете уровня (`BossAbility`):
- **Щит** — своя синяя полоска прочности; пока щит цел, урон по боссу не проходит. Сломан — через 8 с включается снова.
- **Таран стены** — удар с двойным уроном и откат назад.
- **Разрушение башен** — раз в 9 с выбранная башня мигает красным и рушится.

По умолчанию: 1-й уровень — щит, со 2-го — все три.
Перед боем с боссом — диалог (реплики настраиваются в ассете уровня или у спавнера).

### Йог-Сотот
Появляется примерно на трети пути к боссу уровня (уровни 4+):
1. быстро идёт к стене и **неуязвим**;
2. останавливается в 100 px от стены, перед ним вырастают **3 щупальца** (уязвимы);
3. атакует: сначала **рушит башни**, без башен — бьёт стену **двойным уроном**;
4. щупальца уничтожены → Йог уязвим и **умирает за ~3 попадания**.

## Кампания: 30 уровней

Ассеты `Assets/Resources/Levels/Level_01 … Level_30` (список — `LevelCatalog`). В каждом:

- название и описание;
- число убийств до босса (по умолчанию 150 + 25 за уровень);
- свои враги и множитель их здоровья;
- префаб босса, **флажки способностей**, множитель здоровья;
- реплики босса;
- список **мини-боссов** (префаб, после скольких убийств, способности, здоровье).

Новая способность босса = новый флаг в `BossAbility` + реализация в `BossAbilities`.

## Деревня и квестгиверы

**Сцена:** `Village`. Открывается после каждого уровня.

- **Панорама города** по мотивам городов *Героев 3* (листается по горизонтали):
  замок в центре, гильдия магов слева, таверна и кузница внизу слева, рынок, ратуша, конюшня, казармы,
  храм наверху справа, пристань у воды.
- **Все здания кликабельные**: клик открывает окно со списком жителей.
- **Житель** — квестгивер: клик → разговор с героем.
  Если у жителя есть задание, играется его сцена (см. «Задания»), иначе — обычный разговор:
  *«УУУУУ» — «ААААА» — «Спасибо»*.
- Над зданием, где ждёт задание, горит метка **«!»**; внутри такая же метка стоит у нужного жителя.
- Кнопка внизу: «К следующему бою» (в лобби) или «Отправиться в путь» (если уровни города пройдены).

### Данные города
`Assets/Resources/Towns/Town_01 … Town_30` (`TownDefinition`, список — `TownCatalog`):
- название, фон, цвета неба/земли, пропорции панорамы;
- **здания:** название, описание, картинка или заглушка, **место на панораме** (`area` — доли от левого верхнего угла);
- **жители:** имя, портрет, свои реплики на случай, когда задания нет;
- **ряд карты** (`fixedMapRow`) — для сюжетных городов, которые должны всегда стоять на одном месте карты.

Новые здания и жители добавляются в ассете — сцену трогать не нужно.

## Задания

Задание — это сцена-разговор у жителя города с условиями появления и последствиями.
Ассеты лежат в `Assets/Resources/Quests` (`QuestDefinition`), список — `Assets/Resources/QuestCatalog`.

**Как задания связаны между собой.** Не напрямую, а через **флаги мира** (`GameStats.StoryFlags`):
одно задание выставляет флаг («торгаш похищен»), другое на него смотрит. Задание знает только про флаги,
поэтому новые задания добавляются без правки старых. Флаги и список выполненных заданий живут один забег.

**Что настраивается в ассете задания:**

| Блок | Поля |
|---|---|
| Где появляется | город (пусто — любой) и `id` здания: `castle`, `mage_guild`, `tavern`, `blacksmith`, `market`, `town_hall`, `stables`, `barracks`, `temple`, `harbor` |
| Когда появляется | флаги, которые **должны** быть выставлены, и флаги, которые **мешают** |
| Кто выдаёт | `id` постоянного жителя здания **или** свой житель (имя, портрет): он приходит в здание вместе с заданием и исчезает после него |
| Сцена | реплики и титры по порядку |
| Итог | текст карточки «Задание выполнено», флаги, которые выставляются и снимаются, награды (те же исходы, что у встреч в дороге) |

**Реплика и титр.** У каждой строки сцены есть вид:
- **Speech** — окно с портретом и именем говорящего (слева житель, справа герой);
- **Narration** — титр по центру тёмного экрана: *«Спустя 2 часа...»*.

Ремарки внутри реплики выделяются курсивом: `<i>(в мыслях)</i>`.

**Первое задание — «Комбинезон Карлсона».** Новый Сарай, рынок, выдаёт Торгаш.
Жители Старого Сарая ищут Рому по одежде; Рома меняется одеждой с торгашом — и похищают торгаша.
После задания торгаш пропадает из здания, выставляются флаги `torgash_kidnapped` и `roma_in_jumpsuit`.

**Как проверить задание за минуту:** *Tools → Vertical Shooter → Quest Tester* → «Играть».
Игра запустится сразу в деревне нужного города, уровни проходить не нужно.

**Новое задание:** *Create → Shooter → Quest* → заполнить → добавить в `QuestCatalog`.

Чего пока нет: выборов и развилок внутри задания, целей «сделай в бою/в дороге», журнала заданий.

## Карта похода

**Сцена:** `Map`. По мотивам *Slay the Spire*.

- В пуле **30 городов**. В каждом новом забеге карта **генерируется заново** (`RunMapGenerator`).
- **10 рядов снизу вверх:** стартовый город → 8 рядов по 2–3 города → финальная цитадель (ромб).
- Дороги только в соседний ряд, **без пересечений и тупиков**, города не повторяются.
- **Сюжетные города** стоят на своих рядах всегда: забег начинается в **Старом Сарае**,
  а **Новый Сарай** — один из городов первой развилки. Остальные города встают случайно.
- Ряд *r* = уровни 3r+1 … 3r+3.
- На экране: пройденный путь (зелёный), текущий город (золотой), доступные города (белые).
  **Нажатие на доступный город намечает маршрут**; окончательно путь выбирается на развилке в дороге.

## Дилижанс

**Сцена:** `Stagecoach`. Раннер на 3 полосы, дорога едет сверху вниз (~1 минута).

| Управление | ПК | Телефон |
|---|---|---|
| Сменить полосу | `←` `→` / `A` `D` | свайп влево/вправо |
| Прыжок | `↑` / `W` / `Пробел` | тап или свайп вверх |

- **Местность:** лес → поле → горы → река. Скорость растёт.
- **Препятствия:** бревно и яма — перепрыгнуть; камень и дерево — объехать; пролом моста (на реке) — через всю дорогу, только прыжок.
- **Подковы** на дороге — валюта для встреч.
- **3 колеса:** столкновение отнимает колесо. Без колёс дилижанс **всё равно доезжает**, но стена начнёт следующий бой с **−30%** прочности.
- **Развилка в конце:** на полосах указатели с городами следующего ряда карты. В какую полосу въехал — туда и приехал.

## Встречи в дороге

По мотивам *Hand of Fate*. Два путника за поездку открывают **карту встречи**:

1. текст события и варианты (у некоторых — цена в подковах);
2. у **рискованного** варианта перемешиваются **карты удачи** рубашкой вверх
   (большой успех / успех / неудача / большая неудача) — игрок тянет одну;
3. итог с последствиями.

**Исходы** (`EncounterEffectType`): опыт, урон %, башня, колёса, прочность стены,
повреждение стены к следующему бою, уровень случайной стихии, подковы.

В колоде 7 встреч: Раненый путник, Торговец амулетами, Разбойники, Заброшенная кузница, Странный алтарь,
Плотники у моста, Гадалка. Новая встреча: *Create → Shooter → Encounter* → добавить в `Assets/Resources/EncounterCatalog`.

## Сохранение, поражение и конец похода

### Сохранение
- Забег пишется в `run.json` (папка `Application.persistentDataPath`) **при входе в лобби, деревню и на карту похода**,
  а также после выполненного задания.
- Бой и поездка не сохраняются: если закрыть игру посреди них, «Продолжить» вернёт на последний экран, бой начнётся заново.
- Брошенный бой (выход в лобби/меню, закрытие игры) **откатывает** всё, что получено в нём, к сохранению перед боем.
  Статистика похода (убийства, время, поражения) при этом остаётся.
- **Главное меню:** «Продолжить» доступно, только если есть сохранённый забег. «Новая игра» удаляет старый забег.
- Сохраняется: характеристики героя, опыт, стихии, скин, уровень кампании, карта похода и положение на ней, подковы,
  повреждение стены, флаги мира, выполненные задания, статистика. Формат — `RunSaveData` (JSON, есть номер версии).

### Поражение = повтор уровня
Стена разрушена → экран поражения:
- **«Повторить уровень»** — прогресс откатывается к сохранению перед боем, бой начинается заново (+1 к поражениям);
- **«Завершить поход»** — конец забега (нажать дважды: защита от случайного нажатия).

### Конец похода и наследие
Поход заканчивается **победой** (босс 30-го уровня) или кнопкой **«Завершить поход»** (лобби, экран поражения).
Сцена `RunEnd` показывает итоги: уровни, боссы, убийства, города, задания, поражения, время, рекорд.

За поход начисляется **слава** (константы в `RunSummary`):

| За что | Слава |
|---|---|
| пройденный уровень | 10 |
| выполненное задание | 15 |
| посещённый город | 5 |
| каждые 100 убийств | 2 |
| победа | 200 |

Слава тратится в окне **«Наследие»** (главное меню и экран итогов). Улучшения действуют на **каждый новый поход**:

| Улучшение | За уровень | Уровней | Цена 1-го уровня |
|---|---|---|---|
| Крепкая стена | +10% прочности стены | 5 | 40 |
| Острые пули | +5% урона | 5 | 50 |
| Запас подков | +3 подковы на старте | 3 | 30 |
| Своя башня | +1 башня на старте | 2 | 120 |

Цены и силу правят в `Assets/Resources/MetaUpgradeCatalog` (каждый следующий уровень дороже в `costGrowth` раз).
Наследие хранится отдельно от забега — в `meta.json`.

## Ощущение от ударов и производительность

**Эффекты** (`GameFeel`, сила — в константах там же):
- **тряска камеры:** удар по стене (чем сильнее удар, тем сильнее тряска), взрыв, разрушенная башня, появление и смерть босса;
- **осколки:** при попадании (2 штуки) и смерти врага (10, у босса — 40), при разрушении башни;
- **вибрация телефона:** только сильные удары — таран босса, Йог, разрушенная башня, смерть босса (не чаще раза в 0,6 с).

Флаги `ShakeEnabled`, `ParticlesEnabled`, `VibrationEnabled` — задел под меню настроек.

**Пул объектов** (`ObjectPool`): пули, всплывающие цифры и обычные враги не создаются и не удаляются заново,
а выключаются и переиспользуются. Это убирает подтормаживания на телефоне, когда на экране 80+ врагов.
Боссы, мини-боссы со способностями, Йог и щупальца создаются как обычно.
Новый объект в пуле: `ObjectPool.Spawn` / `ObjectPool.Release` и интерфейс `IPoolable` (сброс состояния прошлой жизни).

## Как заменить арт и анимации

### Папка `Assets/Art`: арт подключается сам
Положите картинку в `Assets/Art` под именем слота — и она встанет на место без инспектора:

| Имя файла | Куда встанет |
|---|---|
| `Player.png`, `EnemyPig.png`, `IconDamage.png` … | слот каталога визуала |
| `Town_05.png` | фон города № 5 |
| `building_castle.png` / `Town_05_building_castle.png` | здание во всех городах / только в одном |
| `npc_trader.png` / `Town_05_npc_trader.png` | портрет жителя во всех городах / только в одном |
| `encounter_Bandits.png` | картинка встречи |
| `skin_Golden.png`, `skin_Golden_icon.png` | скин оружия и его иконка |
| `quest_CarlsonJumpsuit.png` | портрет того, кто выдаёт задание |

- Полный список слотов с размерами и отметками «подключено / заглушка» — **`Assets/Art/ART_LIST.md`** (пишется автоматически).
- Подробная инструкция — `Assets/Art/README.md`. Всё, что неясно куда класть, — в `Assets/Art/Inbox`.
- Подключение срабатывает при импорте файла, а также по *Tools → Vertical Shooter → Art → Apply Art From Assets-Art*
  и *Update Project (safe)*.
- В сцене `Battle` герой, стена и фон оформлены вручную («Свой спрайт» / «Своя модель») — это важнее каталога.

### Картинки и модели
Каждый игровой объект рисуется через компонент **Visual Slot**: логика на корне, картинка — в дочерних `Visual`/`Model`.

- **Всем объектам типа** (всем свиньям, всем башням…): *Tools → Vertical Shooter → Select Visual Catalog* →
  в записи нужного `Id` заполнить **Sprite** или **Prefab** (анимированный спрайт, 3D-модель).
- **Одному объекту:** в его `Visual Slot` — «Свой спрайт» / «Своя модель» / «Свой текст подписи».
  Или просто перетащить спрайт в `SpriteRenderer` дочернего `Visual` — код его не затрёт.
- Положение картинки: поля «Смещение / Поворот / Масштаб» или двигать `Visual`/`Model` мышкой — сдвиг запоминается.
- Иконки интерфейса — `UI Visual Slot` (то же самое для `Image`).
- Картинка: `Texture Type = Sprite (2D and UI)`. 3D-модели — шейдер `Universal Render Pipeline/2D/Sprite-Unlit-Default`.

### Анимации
Компонент **Character Animations** (стоит на герое, стене, башне, врагах, боссе). Ячейки:

| Ячейка | Когда вызывается |
|---|---|
| Idle | по умолчанию; враг — у стены между ударами |
| Move | враг идёт |
| Attack | выстрел героя/башни, удар врага по стене |
| Hit | получил урон |
| Death | смерть (последний кадр замирает) |
| Special | щит босса, перезарядка героя |

В ячейку — **Animation Clip** или просто **кадры-спрайты** с частотой. У каждой ячейки своя скорость.

### Герой и оружие
- Оружие крепится к кости руки модели (`RightHand` ищется автоматически) и плавно следует за ней.
- Тело героя поворачивается за прицелом — режим `Body Aim`: `RotateWithWeapon`, `TurnToFace3D`, `FlipX`, `None`.

### Расстановка на сцене боя
Двигаются мышкой в сцене `Battle` (подписаны в окне Scene):
- `EnemySpawner` — линия появления врагов (ширина — `Spawn Width`), `BossSpawnPoint` — точка босса;
- `Towers/Slot_1…5` — места башен;
- `Player`, `Wall` — как обычно.

### Ключевые принципы
- **Данные отдельно от кода.** Уровни, города, встречи, стихии, скины, арт — ассеты в `Resources`; их правят без программиста.
- **Прогресс — в `GameStats`** (статический класс): живёт между сценами, сбрасывается «Новой игрой».
  Там же флаги мира и выполненные задания.
- **Пауза — `GamePause`**: несколько источников (меню, выбор награды, диалог, встреча, Game Over) ставят/снимают свою паузу.
- **Синглтоны регистрируются в `OnEnable`**: в проекте выключена перезагрузка домена при входе в Play Mode.

Меню **Tools → Vertical Shooter**:

| Пункт | Что делает |
|---|---|
| **Update Project (safe)** | Добавляет в проект недостающее (ассеты, компоненты, сцены), **не трогая ручные правки**. Запускать после `git pull`, если что-то новое не появилось |
| Build Vertical Game | ⚠️ Пересоздаёт сцены и префабы **с нуля** — ручная работа (модели, расстановка) пропадёт. Только для пустого проекта |

## Баланс

Проверяется **симулятором** (`Simulate Balance`): «человекоподобный» бот (меняет цель раз в 0.6 с, промахивается на ±8°)
проходит 20 уровней подряд; стена в худший момент держит 241–300 из 300, бои — от 2 до 5.5 минут.
Есть и режим «идеального стрелка» (`RunBatchIdeal`).

Где крутить:
- **`EnemySpawner`** (сцена `Battle`): интервал и размер групп, лимит на экране, удвоение потока, льготные минуты,
  рост здоровья (за уровень кампании, по времени, за уровень героя), что делать с врагами при появлении босса;
- **префабы врагов** (`Pig Enemy`): здоровье, скорость, урон, опыт;
- **ассеты уровней**: убийства до босса, множители здоровья, способности, мини-боссы;
- **`ExperienceSystem`**: кривая опыта, сколько вариантов наград;
- **`GameStats`**: базовые значения героя и стены, шаги и пределы навыков;
- **`Yog_Sothoth`**: дистанция остановки, щупальца, «попаданий до смерти» после щупалец;
- **дилижанс** (`StagecoachRun` в сцене `Stagecoach`): длина поездки, скорость, частота препятствий, штраф за поломку.

После правок — прогнать `Simulate Balance` и `Run Smoke Test`.

## Правила работы с репозиторием

- Работаем в **Unity 6000.6.4f1**. Если коммит изменил `ProjectSettings/ProjectVersion.txt` на другую версию — верните.
- Проект открывать из **корня репозитория**. Не держите внутри папки проекта второй клон — он не попадёт в git и легко перепутать.
- Для обновления сцен и ассетов — только **Update Project (safe)**, не «Build Vertical Game».
- Перед `git pull` закройте Unity. Конфликты в сценах (`.unity`) решаются тяжело — договаривайтесь, кто правит какую сцену.
- Коммитьте `Assets`, `ProjectSettings`, `Packages`. Папки `Library`, `Temp`, `Logs`, `UserSettings` и архивы `*.zip` исключены в `.gitignore`.
- GitHub не принимает файлы больше 100 МБ.
